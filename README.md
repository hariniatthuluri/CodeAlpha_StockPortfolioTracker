# 📊 Stock Portfolio Tracker

A simple and practical Python project to track stock investments and calculate total portfolio value.

---

## 🚀 Features

- Input stock symbols and quantities
- Uses predefined stock prices
- Calculates total investment value
- Clean terminal output
- Option to export data to CSV file

---

## 🛠️ Tech Stack

- Python
- CSV File Handling

---

## ▶️ How to Run

```bash
python main.py
